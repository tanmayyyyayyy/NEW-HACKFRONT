# SkillForge design

## Visual system

Graphite backgrounds, softly tinted neutral surfaces, and an apricot accent for the current route, selected node, and primary action. Use Geist for interface and display text, with monospace reserved for paths, hashes, and dates. The hero artwork uses layered optical glass and a single lit path as a visual counterpart to a traced repository decision.

| Token | Value | Role |
| --- | --- | --- |
| Canvas | `#111115` | Page background |
| Surface | `#19191f` | Workspace, trace, and graph panels |
| Raised | `#222229` | Controls and selected navigation backgrounds |
| Border | `#35343d` | Structural separation |
| Foreground | `#f6f1ed` | Primary text |
| Muted | `#b6adb2` | Secondary text |
| Accent | `#ffab80` | Selection, focus, and primary actions |

## Interaction

The homepage leads to the workspace and graph. The trace preview reveals the newly selected evidence with a short directional wipe. The graph focuses on one node, with separately labeled inbound and outbound connections. The node index remains searchable and keyboard-accessible. Use reduced-motion preferences to disable transitions and directional reveals.
