# SkillForge persona and use-case matrix

| Segment | Two tasks | Product path | Evidence level |
| --- | --- | --- | --- |
| New engineer taking ownership at a product startup | Trace a historical decision to a PR and author. Export a cited handover note. | Private handover and decision trail download | Authorization and graph covered with fixtures. Live private organization pilot pending. |
| Upcoming developer learning an unfamiliar company codebase | Follow an issue to a fix. Compare an earlier decision with the PR that superseded it. | Public repository desk, Futon examples and source links | Local Neo4j scenarios. Hosted walkthrough pending. |
| Engineering manager or tech lead | Find who recorded a decision before assigning ownership. Review evidence gaps when a change has no documented rationale. | Source author/date and explicit abstention | Source attribution and abstention supported. Ownership assignment remains in GitHub. |

GitHub controls private repository grants. Private repository tokens stay in browser memory while in use. Sarvam receives evidence only if the user selects the explanation checkbox. Scaled deployment would move the identity store to managed PostgreSQL, coordinate quotas across instances and add permission-aware indexing with revocation before caching private results.
