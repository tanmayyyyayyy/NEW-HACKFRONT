# SkillForge market fit canvas
Pilot hypothesis for the hackFront finale. Customer interview results and paid adoption are still open.

| Question | Pilot answer and evidence |
| --- | --- |
| First user | An engineer joining a 10–100 engineer product team who needs to take ownership of an unfamiliar service. Validate with three engineers who recently inherited code. |
| Problem | The original author can leave before explaining why a decision changed. Ask participants to show the last time they had to reconstruct a change and record the time spent. |
| Alternative | GitHub search, git blame, PR review, internal docs, asking a teammate or using a code assistant. In each interview record which one they actually used and what it cost. |
| Value | Follow the original PR to a later override, inspect the source and export the trail for the next owner. Compare completion time and citation accuracy with the participant’s usual workflow. |
| Buyer and price | Engineering manager overseeing onboarding and handovers. Test ₹400 per active engineer per month. For ten seats at ₹4,000/month, break-even for the buyer is four engineer-hours saved per month at an assumed ₹1,000/hour. Both inputs need buyer confirmation. |
| Opportunity | GitHub reported over 17 million developers in India in its 2024 Octoverse. This measures developer reach. Estimate paying teams separately from qualified pilots and conversion. [GitHub Octoverse](https://github.blog/news-insights/octoverse/octoverse-2024/) |
| Competition | Benchmark GitHub’s PR search and an assistant with repository access on the same three questions. Measure correct source, recognition of an override and willingness to abstain. Publish results after testing. |
| First 100 users | Recruitment targets: 5 product teams × 10 onboarding engineers, 5 open-source communities × 6 contributors and 2 campus clubs × 10 developers. Track activated users who open a source and return for a second repository question. |
| Validation | Log each participant’s prior workflow, observed task outcome, feedback and resulting change in customer-interviews.md. Record payer interviews separately. |
